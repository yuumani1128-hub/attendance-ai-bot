# 勤怠問い合わせAIボット
社内で発生する勤怠に関する問い合わせ対応を効率化するために開発したAIチャットボットです。  
勤怠ルールの確認はシステムが回答し、個別対応が必要な問い合わせは管理者への確認を案内することで、管理者の負担軽減を目指しています。

## 画面イメージ

![勤怠問い合わせAIボット](images/chat-ui.png)

---

## 1. 背景

管理業務では、以下のような問い合わせが日常的に発生します。

- 遅刻時の対応
- 電車遅延時の対応
- 打刻漏れ
- 勤怠の記載ミス
- 午前休・午後休の取得方法
- 休日出勤の申請方法

これらは何度も同じ内容を説明することが多く、問い合わせ対応に時間を取られるという課題がありました。

そこで、ルール確認はAIが対応し、人の判断が必要な問い合わせのみ管理者へ案内するチャットボットを開発しました。
---

## 2. 主な機能

- チャット形式の問い合わせ画面
- 問い合わせ内容の分類
- カテゴリ判定
- 勤怠ルールの自動回答（rules.txt参照）
- 管理者確認用テンプレートの表示
- セッション中のチャット履歴保持
- Git / GitHubによるバージョン管理

### 6. セットアップ

1. リポジトリを取得
git clone <repository-url>
cd attendance-ai-bot
2. 必要なライブラリをインストール
pip install -r requirements.txt
3. アプリを起動
streamlit run app.py

---

### 7. 工夫した点

- AIにすべての問い合わせを任せるのではなく、ルール確認と管理者対応を切り分ける構成にしました。
- 回答ロジックを分離し、将来的にOpenAI APIなどのLLMへ差し替えやすい設計を意識しています。
- 現在はrules.txtを参照していますが、ConfluenceやBoxなど社内ドキュメントへの拡張を想定しています。
- 最小構成（MVP）から開発を開始し、段階的に機能を追加しています。
